## How to read this

Counts above come from compact `*.summary.txt` files in the private repo. The full raw outputs (basedpyright JSON, semgrep JSON, pytest JSON) live in `mcp/.deploy-reports/raw/` and are NOT committed — they would balloon git history. Each committed summary carries a `raw_sha256` so the operator can verify a local raw matches the deploy run.

Semgrep is **blocking** (Gate 1c) — every NEW finding fails the deploy. One pre-existing pattern is baselined via inline `# nosemgrep:<rule-id>` annotations with rationale; `grep -rn nosemgrep mcp/server` lists every active waiver. Baseline count is read from `mcp/.deploy-reports/semgrep-baseline.summary.txt` (`baseline_count=1`) — this sentence is regenerated on every deploy, not hand-edited.

See `mcp/.deploy-reports/README.md` (private) for the full doctrine.
